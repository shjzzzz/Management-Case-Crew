# Research Question（S1：单一案例选题收敛与证据可行性评估）

## 1. 目标与边界
把宽泛的管理学或涉税主题收敛为 **≤3 个可落地的单一案例研究候选题目**，逐一评估案例典型性、核心张力与证据可得性，并推荐一个最优选题交研究者拍板。**不在此直接展开文献综述、测算或开对策。**

## 2. 前置读取
- 读取 `Meta/purpose.md`（若未填先提醒，不代编研究方向）、`Meta/decisions.md`、`Meta/constraints.md`、`Meta/index.md` 与 `Meta/link-map.md`。

## 3. 核心收敛流程
1. **厘清现实与管理张力**：区分“单纯描述企业做了什么”与“具有管理学理论/税法合规分析价值的真问题”（如为什么内控看似完备却仍触发偷漏税稽查；如何在商业实质约束下实现合规税负优化）。
2. **产出 ≤3 个候选单一案例选题**，每题必须写清：
   - 案例企业/对象与行业情境（典型性 / 极端性 / 启示性依据）；
   - 分析单位与时间窗口；
   - 核心管理与涉税问题（1–2 句，可诊断、可核验）；
   - 拟借用的管理理论视角（如 COSO / 委托代理 / 价值链 / 业财税融合）与关键税法议题；
   - **证据可行性评估**：公开年报/公告、税务稽查/处罚文书、内控制度、可及访谈资源与保密风险；
   - **最大失败风险**（如公开数据缺失、涉密无法披露、合规边界模糊）。
3. **给出明确推荐**：比较 3 个候选的学术/实践价值与证据可得性，推荐 1 个最优方案并说明取舍理由。

## 4. 产出与停点
- 输出：候选选题对比表、推荐方案及待研究者确认的边界问题；经研究者批准后写入 `01-Research-Projects/<项目>/PROJECT.md` 的第 1 节，推进至 S2 `/literature-review`。

## 5. 硬性禁止
禁止编造案例企业财务状况、处罚文号或内部数据可得性；禁止替研究者拍板最终选题（A3）。
