# 写作风格指南（研究者填写；MBA 案例论文写作与精修必须遵守）

> 未填写的项，AI 使用中性严谨的管理学学术文风，并在需要时用 `⟦问：…⟧` 询问，不替研究者设定偏好。

## 语言与文风
- 主语言：中文（保留标准英文术语，如 COSO、ERM、ETR、GAAP）
- 句式偏好：待定（建议：问题导向、证据驱动、逻辑严密，避免空泛口号）
- 避免：夸大（“彻底解决”“显著提升”）、无来源断言（“企业普遍存在”）、理论与案例“两张皮”

## 术语表（中英对照与固定译法）
| 英文 | 固定译法 | 备注 |
|---|---|---|
| tax compliance | 税收遵从 | |
| tax evasion | 偷漏税 / 逃税 | 须严格区分于合法税收筹划 |
| tax planning | 税收筹划 / 税务筹划 | 强调真实商业实质与合法前提 |
| effective tax rate (ETR) | 有效税率 | 须注明分子分母口径 |
| triangulation | 三角验证 | 多源证据交叉印证 |

## 引用与格式
- 正文引用格式：待定（按培养单位 MBA 学位论文规范，如 GB/T 7714）
- 数字与财务指标写法（小数位、单位万元/亿元、同比口径）：待定
- 表格与图的注释写法（注明数据来源与计算口径）：待定

## 证据措辞分级（默认；研究者可改）
| 证据状态 | 允许的措辞 |
|---|---|
| 多源三角验证成立（财务/法规+访谈/内控） | “…导致/反映出…”，并指向具体证据链与测算 id |
| 单一来源或部分印证 | “…提示/访谈反映…；结合…有待进一步核实” |
| 仅理论推测 | “从…理论视角看，可能存在…”，不得写成已证实事实 |
